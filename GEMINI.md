# GEMINI.md

## Directory Overview

This directory contains the product requirements for a "Document Intelligence Platform." The core purpose is to build a system that helps users manage, analyze, and extract insights from unstructured business documents. The project is currently in the planning and documentation phase.

## Key Files

*   **prd.md**: The main Product Requirements Document (PRD). It outlines the project's objective, target audience, core features, technical stack, and future plans. The document is structured as follows:
    *   **Objective**: Build a system for uploading, categorizing, and extracting insights from business documents.
    *   **Problem Statement**: Addresses the challenges of managing unstructured documents manually.
    *   **Target Audience**: Small to medium-sized businesses and departments within larger enterprises.
    *   **Core Features (Phase 1)**: Document upload, management, auto-categorization, insight extraction, and a chat interface for Q&A.
    *   **Extended Features (Phase 2)**: Email and shared drive integration for automatic document fetching.
    *   **Technical Stack**: Recommends a stack including React for the frontend, Node.js/Python for the backend, and OpenAI for the AI layer.
    *   **UI Flow Overview**: Describes the user interface for the home page, document detail page, and settings page.
    *   **AI Prompting Strategy**: Provides example prompts for categorization, extraction, and insight generation.
    *   **Success Metrics**: Defines key metrics to measure the success of the platform.

## Usage

This directory is for product planning and documentation. The `prd.md` file serves as the single source of truth for the product's vision and requirements. It should be used to guide the development of the "Document Intelligence Platform" and to ensure that all stakeholders have a common understanding of the project goals.
